# EQM (EventQuoteMate)

Problem-Solving Statement

Event hosts often struggle to find skilled organizers, while event organizers lack a centralized platform to discover and bid on opportunities. Traditional hiring methods are inefficient, costly, and lack transparency in pricing and quality. EQM (EventQuoteMate) solves this problem by providing a bidding-based marketplace, where event hosts can post event details, organizers can bid competitively, and the best match is selected based on price, experience, and reviews—ensuring efficient and reliable event planning.

Key Features

✅ Event Posting & Bidding System – Hosts list events, and organizers place competitive bids.✅ Real-Time Chat & Notifications – Secure in-app messaging and push notifications for quick communication.✅ Location-Based Event Discovery – Organizers find nearby events using Google Maps API.✅ Secure Payments with Razorpay – Smooth transaction processing between hosts and organizers.✅ Organizer Profiles & Reviews – Verified profiles with ratings, experience, and portfolio.✅ Firebase Authentication – Secure user login via Google, email, or phone.✅ Offline Access with Firestore – Store event details & bid history locally for quick access.✅ Firebase SMS & Email Notifications – Automatic alerts for bid updates, confirmations, and event reminders.✅ Geo-Fencing & Activity Tracking – Alerts for nearby events and tracking organizers on their way.

Tech Stack

Frontend: React Native

Backend: Firebase

Database: Firestore

APIs: Google Maps API, Razorpay

Authentication: Firebase Authentication
